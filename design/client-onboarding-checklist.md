# Client Onboarding Checklist

Internal use — run through this every time a new client says yes, so nothing gets missed and
every client gets the same standard of start, regardless of how small the job is.

## Day 0 — the moment they agree

- [ ] Confirm scope and price in writing (email is fine) — this becomes the basis of the
      Project Agreement (`design/project-agreement-template.md`)
- [ ] Send the filled-in Project Agreement for the client to countersign/confirm (skip formal
      sign-off only for very small, low-risk jobs like a single flyer)
- [ ] Send the deposit invoice via Stripe
- [ ] Add the client to whatever tracking you're using (spreadsheet, CRM, or the `leads/`
      folder in the repo) with: name, service, price, start date, estimated delivery

## Day 0–1 — once the deposit lands

- [ ] Confirm receipt of deposit to the client, confirm the start date
- [ ] Request anything you need from them to start (content, logo files, access/logins,
      brand assets, examples they like) — send ONE clear list, not several follow-up emails
- [ ] Set an internal reminder for the estimated delivery date

## During the project

- [ ] Share progress at agreed check-in points (don't go dark — even a short "still on track
      for [date]" update matters more than people expect)
- [ ] Get sign-off on drafts/concepts before moving to final polish, so revisions stay within
      the agreed rounds
- [ ] Log any scope changes in writing before doing the extra work, and invoice separately if
      it's genuinely outside the original agreement (see Section 5/6 of the Project Agreement)

## Delivery

- [ ] Send the final invoice for the balance
- [ ] On payment, deliver final files / access / handover, per what was promised in Section 2
      of the Project Agreement
- [ ] Ask if they want to keep DSL on for ongoing support (retainer pitch — this is the
      natural moment to bring it up, not a cold follow-up email weeks later)
- [ ] Ask for a testimonial or review while the experience is fresh — don't wait

## After delivery

- [ ] File the finished project in the portfolio/Work page tracker if it's a shareable case
      study (check the client's OK with being named/shown first)
- [ ] If they said yes to a retainer, set up the recurring Stripe subscription and confirm
      billing date
- [ ] If they said no for now, add a note to follow up in 2-3 months — a lot of "not right
      now" turns into "actually, yes" later if you stay in touch without being pushy
